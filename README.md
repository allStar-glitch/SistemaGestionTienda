# Sistema de Gestion de Tienda

## Descripcion

Este es un programa hecho en Java para gestionar algunas operaciones de una tienda.

El programa permite trabajar con productos, clientes y compras, ademas de generar una factura con los datos de la compra.

## Tecnologias utilizadas

- Java
- IntelliJ IDEA

## Como ejecutar el programa

1. Descargar o clonar el repositorio.
2. Abrir el proyecto en IntelliJ IDEA.
3. Buscar la clase principal del programa.
4. Ejecutar el metodo `main`.

## Lo que aprendi

Con este proyecto pude practicar mis conocimientos de Java, trabajando con clases y metodos, y aprender a organizar mejor un programa y sobre todo a usar arrayList, hashMap y linkedList.
